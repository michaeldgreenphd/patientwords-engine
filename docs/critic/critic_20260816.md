   working tree. With the documented site recipe (`'/*' '!/modes/'`) it emitted **153
   `render path missing on disk` FAILs**, every one an artifact — each path was present in
   `git ls-tree -r HEAD`. True reading after materialising `modes/`: 0 errors, 1 known
   orphan-row warning.

Failure mode is identical and it is the dangerous direction: both report a *worse* state

FAIL and that outcome.

Mitigated this cycle at the recipe level (both patterns now in the bootstrap doc, with
reasons). The root fix is `git ls-tree`-based coverage in both scripts — Option B of the
open `BACKFILL-PLANNER-LENS-SPARSE-20260815` decision, still unwritten because it is code
