## MEDIUM-3 — `pab-probe` is a known trigger key with no CI target

From today's doc-accuracy sweep (`docs/audits/doc_accuracy_20260810.md` item 1):
`pab-probe` is in `fire_trigger.TRIGGERS` but has neither
`.github/trigger/pab-probe.json` nor any workflow reading that path. `fire_trigger`
hard-errors on *unknown* keys precisely so a fire cannot silently no-op — but a
*known* key with no workflow does exactly that: it would pass validation, write a
trigger file, journal the fire, push, and run nothing. The journal would then
record a fire that never happened, which is the one thing the journal exists to
prevent. Owner/orchestrator call: wire it or drop the key.
